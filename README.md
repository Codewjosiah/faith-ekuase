16. Animation requirements



The animation is a major part of the experience.



Use the same kind of refined scroll-blur animation as the reference website I showed you.



Required animation style



- Blur-to-sharp text reveals

- Subtle opacity transitions

- Gentle vertical movement

- Smooth image reveals

- Cinematic section transitions

- Slight parallax only where it improves the composition

- No excessive motion

- No flashy particle effects

- No giant animated hearts

- No bouncing elements

- No distracting loading animations



The animation should feel like the page is coming into focus, not like every element is aggressively moving.



Respect "prefers-reduced-motion".



On mobile, keep animations lighter and prioritize performance.



---



17. Responsive design



The website must be excellent on mobile because many brands will open it from their phones.



Mobile requirements



- No horizontal scrolling

- No clipped text

- No oversized headings that break awkwardly

- Portrait image remains visually strong

- Polaroid scales correctly

- Videos remain easy to watch

- Buttons are easy to tap

- Navigation becomes a clean mobile menu

- Contact actions remain obvious

- Sections stack naturally

- Animations remain smooth



Desktop should feel cinematic and spacious. Mobile should feel intentional, not like a compressed desktop layout.
